## File Roles

### Core (`src/simple_matrix/base.cr`)

- `SimpleMatrix(T)` — generic class, type parameter required
- `@buffer : Array(Array(T))` — internal 2D array
- `@width : UInt32`, `@height : UInt32` — dimensions
- Constructors: `(height, width, value?)`, `(height, width, &block)`, `(buffer)`
- `self.identity(n)` — n×n identity matrix
- `size` — total element count (`width * height`)
- `to_s(io)` — pretty-print with box-drawing characters
- `to_json(json)` / `initialize(pull)` — JSON serialization

### Operations (`src/simple_matrix/*.cr`)

Each file extends `SimpleMatrix(T)` with operation methods. All follow the same pattern:

- **Overloads**: most operations accept `SimpleMatrix(T)` or raw `Array(Array(T))`; `mul` and `sum` additionally accept scalar `Number`
- **No dimension validation** — caller must ensure correct sizes
- **Zero-alloc** — results written into pre-allocated buffer

| File | Method | Signature |
|------|--------|-----------|
| `dot.cr` | `dot(other, result)` | m1 · m2 → result |
| `mul.cr` | `mul(other, result)` | m1 * m2 → result |
| `mul.cr` | `mul(value, result)` | m1 * scalar → result |
| `sum.cr` | `sum(other, result)` | m1 + m2 → result |
| `sum.cr` | `sum(value, result)` | m1 + scalar → result |
| `transpose.cr` | `transpose(result)` | m^T → result |
| `convolve.cr` | `convolve(window, result, padding)` | m ⊛ w → result (padding defaults to `{x: 0, y: 0}`) |
| `apply.cr` | `apply(result, &block)` | f(m) → result |
| `each_map.cr` | `each(&block)`, `each_with_index(&block)`, `map!(&block)` | iterate elements; transform in place |
| `compare.cr` | `==(other)`, `==(other_buffer)` | element-wise equality, returns `Bool` |

### Specs (`spec/*_spec.cr`)

- One spec file per operation, mirroring `src/simple_matrix/`
- Fixtures defined in `spec_helper.cr` (various sized matrices with known values)
- Run: `crystal spec` (all) or `crystal spec spec/dot_spec.cr` (single file)
